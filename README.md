## ⚙️ Tipos de Testes Executados

- **Automated E2E Testing:** Validação do fluxo completo de ponta a ponta.
- **Component & Integration Testing:** Testes isolados de endpoints e microsserviços.
- **Regression Testing:** Garanta que novas alterações não quebrem funcionalidades legadas.
- **Load & Performance Testing:** Análise de resiliência e tempo de resposta das APIs sob carga.
